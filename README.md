# Jogo-Patrulha-Mirim-
um jogo educativo para celular e PC onde crianças exploram um quintal em primeira pessoa. O objetivo é achar e tocar em 13 criadouros com água parada para eliminar focos do mosquito Aedes aegypti. Cada ação gera sons, partículas e mensagens práticas de prevenção das arboviroses. Leve, lúdico e roda direto no navegador via link.
